# 设计工作台按使用步骤牵引功能

状态：accepted（2026-11-21）

设计工作台不再按节点类型铺开六段功能，而是按首次交付的先后给出六步：建现场 → 搭台账 → 接设备 → 配策略 → 配界面 → 交付。步骤条常驻面板顶部，标出已完成、当前与未完成；每一步只露出当前要用的功能，节点树提供对象上下文。跨节点的工具与诊断从步骤内的"相关工具"或"工具"按钮进入，不占步骤。

## Considered Options

- **按节点类型铺开全部功能**：信息全，但初次使用面对的是报表和空段，功能之间没有先后。
- **清单首页（原型 B）**：一眼看到全路径和下一步，但每次操作要再点一层；适合总览，不做主形态。
- **全屏向导（原型 C）**：干扰最少，但看不到现场全貌，跳步与回看成本高。
- **硬向导（未完成上一步不能进入下一步）**：路径唯一，但老手被拦住，现场常有并行任务。
- **步骤条＋步内面板（A，采纳）**：可跳步，跳过后仍标未完成；每一步只有一个主按钮，对象树常驻。

## Consequences

- 新建项目从第 1 步开始；已有项目落在第一个未完成的步骤，全部完成时落在交付。
- 在搭台账阶段选中设备或单元，会自动进入接设备；树始终是对象入口。
- 步骤完成度由对象状态推导（有对象、无未绑定设备、有策略、已配总览、已发布），不是手工勾选。
- 配界面：台账树的每一层都可以配自己的总览（指标／设备／报警）；总览工作台读的是所在层的配置，子层不覆盖父层。配置方式是块目录＋声明式绑定＋槽位版式，见 ADR 0009。
- 跨节点的工具按步骤铺在需要它的位置：搭台账 → 模板库；接设备 → 通道、点位表、型号库、设备验证、通信健康与报文；配策略 → 聚合计算、计算点、虚拟输入、报警类型；交付 → 数据保留。不设单独的工具抽屉。
- 接设备支持批量：勾选多台同类设备一次套用型号与通道，生成映射草稿与差异清单；也支持按"设备,型号,通道,站号"导入。批量不代替逐台验证，站号冲突与通道离线要逐条显示，不能被"全部成功"盖住。
- 步骤里不显示没有内容的分区；未绑定的设备只出现"绑定"这一件事。
