# 行业包只表达启用状态，不内建许可与计费

状态：accepted（2026-11-21）

"付费 EMS 行业包"要求底座与包在界面、数据、依赖三层分开，但不要求软件判断谁付过钱。软件只记录某站点是否启用包：未启用时包内页面不可达、依赖它的项目包拒绝运行；许可与计费留在商务流程。已启用的站点保持默认启用，升级不会静默移除能力。

## Considered Options

- **内置许可文件或到期时间**：引入这句话没有要求的机制，离线交付下计时也不可靠。
- **新部署默认停用**：要在没有状态文件的实例上区分"新装"与"升级"，现有注册表做不到可靠区分，代价是一个假的区分。
- **只记录启用状态（采纳）**：代价是"买与没买"在软件里没有技术差异；收益是不把商业条款写进运行时。

## Consequences

- 系统下需要"行业包"页：列出包、版本、启用状态与提供的内容，并能启用/停用。
- 停用不删除包内数据；再次启用时工程对象仍在。
- 销售与合同承担"付费"，产品只承担"是否启用"。
