# 03: 从模板建立并维护真实台账

**What to build:** 从模板创建现场，增建合法子对象、复制子树、搜索和绑定成员；保存后所有工作台看到同一工程。

**Blocked by:** 02

**Status:** approved-local-draft (not published to GitHub)

## Acceptance criteria

- [ ] 模板不携带旧地址、凭据或运行状态。
- [ ] 层级和成员引用由服务端校验，复制后引用正确。
- [ ] 刷新与重启保存，越权与冲突失败可解释。

## Execution boundaries

- Reuse existing Go capabilities; keep the latest prototype UI and safe domain semantics.
- TDD: observe a failing behavior check before implementing; use real Go plus isolated storage/device simulators for acceptance.
- No push, public issue/PR/comment, real-device connection or physical write.
- Report tests actually run and remaining gaps; do not claim complete from mocks alone.
