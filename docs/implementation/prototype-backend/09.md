## Implemented scope

- Canonical project snapshot + device ledger + EMS state/quality drive the default layer. Business Device rows are not duplicated as their own children; project roots and bound-member Units remain selectable. Zero-point/unbound devices are excluded. Unknown runtime devices cannot enter root metrics merely because their point sits below the root.
- Default metric slots come from declared channel/server points, including points without a sample, plus scoped observed points. Saved point IDs and targets remain scoped. Good zero remains `0`; absent, stale and invalid samples do not become current zero or normal running state. Observation time uses `source_time`, while the API evaluation time is explicitly labelled query time.
- Communication uses current backend quality, not a stale ledger health fallback. Running state requires a good observation; maintenance is explicitly unknown where no maintenance observation contract exists. A query/connection failure clears current runtime values and health instead of claiming device offline.
- Live topology shows the current layer's declared device bindings and Unit member roles. The decorative teaching factory remains preview-only. Relationships are labelled organization/member references, not invented physical energy flows. Existing glass layout, six metric slots, scene area, lower tables and side/bottom regions remain.
- Recent data is the named primary metric's last five observations within 15 minutes via the existing history contract; the label makes that default scope explicit. Changes are derived only between valid observations. No event/alarm lifecycle or daily-statistics projection was invented.
- Screen `404 screen_not_found` alone selects the default screen; denied/query/connection failures remain visible. Local read serials and project/session fences discard late screen/history/ledger responses and invalidate on leaving the page. Runtime polls clear failure feedback on recovery.
- No history page/API edits, command implementation, screen configurator, daily statistics or alarm lifecycle work. Go production code was not changed.
