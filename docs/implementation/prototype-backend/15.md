## Local implementation — 2026-11-25

- 基于 `e8eaedeac5d8e01f6dc7dafe16e61fe5a545fa95`，最终验证前已合入稳定 tip `b24728dcc135c25d3e0120c96fa908fbb854c398`；不追其他未合入工作树。
- `App` 生命周期启动 `RunAggregates`：启动时恢复节点定义，定义变化唤醒，约 1 秒节拍持续采样；取消后结束循环、停止 timer 并取消订阅。GET 只读，PUT 只保存定义，不制造观测。
- 窗口为 UTC 对齐的 `[start,end)`，只在完整窗口关闭后产生窗口结果；新定义先为 `pending`，不把配置前的半个窗口当完整窗口。已产出的窗口按定义版本及结束时间去重，迟到样本、重新查看和重启不改写该结果。
- 不是硬实时调度：输出发生在关闭后的采样轮次。停机、过短窗口或过载错过的较早窗口不补造；仅处理可观察到的最新闭合窗口，历史保留缺口。返回实际滞后，不承诺停机时仍“≤一个窗口”。
- 复用既有算子、成员均值、质量策略、观测质量、运行态历史及告警引擎。变量保留明确的 `node_value` 时间依据；物理 Modbus 输入必须来自匹配当前配置的运行态观测。裸缓存值、缺失、过期、未来时间、禁用或坏值不能充当正常观测；无可用成员为 null，不补零。
- 窗口有效成员表示至少贡献一条有效观测，不表示连续时间覆盖率；成员同时给出有效/拒绝样本数。成员历史复用共享 Query 分页，2002 条回归覆盖原先的 2000 条边界；超过共享 10000 条上限或读取失败明确失效，不以截断均值冒充完整结果。
- 输出只写作用范围节点上的聚合数据，不产生 `valueSet` 或设备命令。两种运行态输出点注册到既有复制/项目包排除表；保留定义，不把旧结果及成员运行证据当工程资产携带。

## 17 / 18 消费者契约

- 权威数据是 `easyemsAggregateResult` / `GET /aggregate`：`value`、`quality`、`valid/total`、`members`、`time`、`time_source`、`window`、`evaluated_at`、`lag_seconds` 一起消费。`time` 为瞬时有效成员的最新观测时间或闭窗结束时间；`evaluated_at` 是计算时刻，不能续期源观测。
- 存储中的数值缓存 `easyemsAggregateValue.Time` **仅为 LWW 更新时钟**：同一源时间可以发生值/质量变化。不得直接用它判定观测新鲜。共享 `visibleNodes` 的本次响应副本（快照、WebSocket、项目读者）从结构化证据重建数值及其观测时间；没有结构化证据时不返回可用标量，而是 `pending`/未知。
- `/history?node_id=...&type=easyemsAggregateValue` 与 `/history/export` 复用既有查询、游标、展示聚合和导出上限。原始记录的 `value/quality/source_time` 与结构化证据一致，`received_time` 是计算时间，`text` 保存完整成员/窗口 JSON，CSV 同样保留；没有新增旁路历史端点，也不把旧的裸数值缓存追认成可信历史。
- 当前结果、公开节点树、历史、展示聚合及 CSV 均检查引用成员的**当前**可见范围；成员移出权限范围后拒绝完整聚合读取或移除节点树中的聚合载荷，不能只凭 group 可见泄漏成员值/身份。投影不修改存储或其他身份的响应。
- 18 后续绑定必须读取以上完整证据并校验质量/时间；窗口标识与实际滞后必须保留。本票不实现策略、保护或联锁绑定，也不实现 12 的每日统计。

## Limits

- 这是软件/隔离采集适配器验收，不是真机签收；没有读取或运行继承的 secret launch 配置，没有真实设备连接或写入。
- 本票聚合观测适配消费变量与匹配配置的 Modbus 运行态观测；OPC-UA/MQTT 尚未接入此证据适配，成员按未知处理，不能以裸缓存“有数值”替代成功采集。历史保留/输入采样缺口不做插值或零填充。
- 同进程重启 fixture 使用新 HTTP 连接：既有 SIOT HTTP Stop 只关 listener，旧 keepalive 可命中旧 handler；未扩大本票修改该 HTTP 生命周期。旧聚合 sampler 的退出、取消订阅及停机无样本另行验证。
