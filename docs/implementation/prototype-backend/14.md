## Local implementation

- Extends the existing state-machine definition, planner, API and H5 editor; no second engine. Ordered exit → transition → entry actions share existing guards and typed actions. Published definitions are retained by version; publishing does not dispatch or grant automatic control.
- Machine-only `command_bindings` bind action IDs to a stable business device, declared Profile command and bounded parameters. Resolution, model verification, operation scope, automatic/manual safety and physical dispatch/readback reuse the existing 07 command manager. Profile-mapped raw writes remain refused. Variable actions are software actions, not physical-device feedback.
- Canonical command status and optional process completion readback are separate. A confirmed command is never rewritten because a process condition timed out. The logical state changes only after all required actions/conditions and its persistence are confirmed.
- Event `request_id` is required. A separate keyed `stateMachineRun` intent persists actor, original revision, published source/version, inputs, trace and stable action command IDs before effects. Same-ID retries return the original fact; conflicting semantics are refused. Interrupted intents are reported unknown without replay or inferred state advancement. Runtime event identities have no application TTL and are excluded from project reuse/export; definitions and their references remain.

- Reproduced with real HTTP/store: after an input moved from the reader's Site A into Site B, retained v1/guard/trace and pending source/observations remained visible despite a clean v2. Default simulation and publication validation could also reveal the revoked source.

Inaccessible blocks are omitted with explicit `restricted` markers, not reconstructed from current definitions or represented as nonexistent. All response paths, including writes, replay and persistence-uncertain responses, use the same projection; source validation does not disclose revoked configuration details.
- Generic HTTP snapshot and real WebSocket output no longer expose raw `stateMachineDocument` or `stateMachineRun` points. A `stateMachineDetails=restricted_to_scoped_api` marker directs consumers to the authorized machine API. Internal `visibleNodes`, persisted facts and pending execution gates are unchanged. Projection uses new maps/slices; an authorized admin still reads the original v1, actor and observations after restricted reads.
- H5 accepts a restricted/absent draft and labels restricted evidence explicitly. A hidden execution is not described as an operation that did not run.
- Regression coverage includes clean v2 GET/list, write responses, scope revocation during an event's action delay, safe-event replay with a restricted pending intent, original-event denial, snapshot/WebSocket filtering, unchanged admin facts and the continuing `previous_execution_unresolved` gate. Focused Go checks, seven frontend helper checks, type-check and H5 build are recorded for this patch; the earlier full-suite/browser results are not claimed as verification of this follow-up.

## Limits

- Events are explicitly submitted through the existing API. No background event subscription, implicit enable, automatic restart replay, or new project control grant is introduced.
- Interrupted events are retained as unknown and queried with their original actor/request identity; the process never guesses a post-crash state from device values. A separate deliberate new event is not an automatic retry.
- Existing machines retain process facts during compatible engineering rollback; incompatible definitions and resurrection of a missing machine identity are refused and require explicit handling/import.
- The mutation owner is one runtime with a state-machine mutex. This does not claim multi-writer distributed execution or physical-device acceptance.
- Existing 07 PumpHouse `unknown(clock_basis_inconsistent)` and bootstrap timestamp findings remain open; a passing run is not closure of those findings. No guards were weakened and no baseline failure is rerun until green.
