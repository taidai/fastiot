# 03: 规则重复条件提示

**What to build:** 交付人员在决策表里编辑条件组时，如果与同一张表里另一条件组完全相同，编辑处直接标出"重复"，帮助发现无意义的分支。只提示，不阻断保存，不改判定结果。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 条件组完全相同时，行内出现"重复"标记（与原型用词一致）
- [ ] 仅部分相同或顺序不同但语义相同的情况，按"完全相同的条件集合"判定，不误报
- [ ] 不阻断保存与发布，不改变模拟与运行结果
- [ ] 判定逻辑是纯函数并有测试：相同、不同、空条件三组用例
- [ ] 类型检查、H5 构建、既有 Node 测试通过
