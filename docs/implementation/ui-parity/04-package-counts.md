# 04: 项目包计数补齐

**What to build:** 交付页的"包内容"要说出原型那句话：多少个对象、多少台设备、多少台已绑定、多少条规则与状态机。现在后端只给节点数、采集点数、画面数、策略数，设备与状态机计数缺失，前端只能显示半句话。本票把计数补进接口，并让交付页按原型文案渲染。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 包摘要接口返回设备数、已绑定设备数、状态机数（字段含义写进契约注释）
- [ ] 计数来自与导出相同的工程事实，不由前端二次统计
- [ ] 未发布或读取失败时显示"—"，不得用 0 冒充
- [ ] 交付页"包内容"按原型文案显示，采集点用"采集点"而非"工程点位"
- [ ] Go 测试覆盖有设备/无设备两种情况；类型检查与 H5 构建通过
