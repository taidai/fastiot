# 07: 设备表与最近数据按原型列

**What to build:** 总览主区的两张表与原型对齐语义：
- 设备清单：列为「设备 / 类型 / 状态 / 主要值 / 通信 / 更新」。状态由通信与运行反馈共同决定（在线、离线、停止），不再用「运行 / 维护」两列拼接。
- 最近数据：是**时间序列表**——一行一个观测时间点，列由该层画面绑定的点位决定（原型为时间、出口压力、目标、电流、液位），不再按点位逐行显示"当前值/质量/观测时间"。

**Blocked by:** None（主题令牌与三栏结构已合入）

**Status:** ready-for-agent

- [ ] 设备表列名与顺序同原型；状态取值有真实来源（通信 + 运行反馈），缺失显示「—」
- [ ] 最近数据按时间点成行，点位成列，最多 5 行 × 绑定列；缺失值显示「—」，不补值
- [ ] 数据来自现有接口（观测/历史），不新增存储、不伪造
- [ ] 视觉差异工具复测：主区（不含三维场景）下降；整体不劣化
