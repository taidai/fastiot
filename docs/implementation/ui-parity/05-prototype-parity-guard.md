## 未覆盖范围（正文）

本守卫锁定的是结构与语义，不替代视觉或现场验收：

- **像素级视觉**：只断言元素存在、文案与计数，不比对颜色、字体、间距或与原型 HTML 的逐像素差异。玻璃样式、平台字体渲染差异不在此守护。
- **真机**：种子来自回环 Modbus 模拟器，所有"已接入"证据都是软件证据；守卫从不连接真实设备，也不构成现场签收。
- **权限受限视角**：守卫以管理员运行，只覆盖管理员看到的页面；受限账号的对象范围过滤、动作白名单与只读演练由 Go 集成测试覆盖，不由浏览器守卫重复。
- **未配置/异常分支**：只覆盖种子项目的正常态；空项目、后端不可用、读取失败等分支靠 Node 合同测试与 Go 测试兜底。

设计工作台的设备三态在真实页面上另有一组断言：守卫会先把一台种子站号映射到 Profile 的全部必需点位并保留人工验证，然后断言它显示「已绑定待验证」而不是「已接入」；同时断言没有任何缺少完整 L2 证据的设备读到「已接入」。
