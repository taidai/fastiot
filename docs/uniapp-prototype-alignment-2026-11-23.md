# uniapp 与最新版原型对齐返工（2026-11-23）

## 问题

上一批完成的是功能接通与托管验收，不是原型一致性验收。当前实现把原型简化成通用卡片页，布局、密度、玻璃层次和部分主工作区均未按原型实现。不能用“无溢出、接口可用”替代视觉与结构对齐。

## 唯一基准

- `frontend/prototype/overview-hd/总览 · 玻璃磨砂.html`
- `frontend/prototype/overview-hd/设计 · 玻璃磨砂.html`

- 同目录 1280×800 截图：`frontend/evidence/uniapp-compare/prototype-*.png`

原型中的数据只用于理解布局，不得进入生产。现有真实 API、类型和合同测试继续作为数据边界。

- 还原浅蓝青绿色模糊光斑、网格与厚玻璃边、内侧高光、阴影层级。
- 顶栏按原型组织品牌、项目、同步元信息、三工作台、外观和告警。
- 三栏：200px 台账 / 主舞台 / 320px 右栏；六指标层、工艺主视觉、设备与最近数据双栏、右栏告警/今日执行/摘要。
- 无数据保留结构并显示 `—`，不得用空态文案替代整个工作区。
- 历史保持真实数据能力并应用同一视觉体系。

## B：设计工作台（独立会话）

文件：设计页面及 design 组件，不改共享玻璃和 TopBar。

- 六步不是说明卡；按原型形成步骤条、左侧台账、当前步骤完整工作区。
- 接设备和策略保留已实现真实功能，视觉上纳入原型工作区。
- 配界面按原型形成块/槽位列表面板与客户预览双栏；后端不支持编辑时，预览和配置项明确只读，不伪造保存。
- 建现场/搭台账展示真实对象与下一步，不再只是大段说明。

## C：交付工作台（独立会话）

文件：交付页面及 delivery 组件，不改共享玻璃和 TopBar。

- 主视觉以“当前版本/依赖/绑定/预检摘要 + 包内容”双卡为主。
- 下方版本列表、跨实例交付；预检门槛可展开查看，不占据整页主视觉。
- 保留真实预检、冻结、导入导出、回退、证据、权限、审计和行业包。
