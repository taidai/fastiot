# 客户视图净化清单

- 日期：2026-11-20
- 来源：以 operator 账号在隔离实例中逐页实际使用后整理的客户侧问题
- 原则：客户视图不出现内部术语、实现限制与交付动作；同一份数据在交付视图保留原词
- 范围：客户工作台（运行 → 总览 / 画面 / 报警，以及由它们进入的历史与通信健康）

## A. 文案改动

### A1 总览 · 空状态

同一屏幕有三处对 `—` 的解释，互相重复且其中一处把客户指向交付动作。

| 位置 | 现在 | 改成 |
|---|---|---|
| 指标区提示 | 还没有可展示的指标：先接入通道与点位，这里会自动出现收益、用电与需量。 | 尚未接入的数据暂不显示；如需接入设备，请联系交付人员。 |
| 底部状态栏 | 现场：仅展示已绑定点位；未接入指标显示"—"，不生成模拟数据。 | 未接入或过期的数据以「—」表示，不会用估算值填充。 |
| 页脚 | 数据来自已配置点位；未接入或过期的值显示"—"，不生成模拟数据。 | 删除（与状态栏重复） |

同时：**没有绑定来源的指标不再占位显示**，只有"已绑定但暂无数据"才显示 `—`。

### A2 总览 · 点位操作

| 现在 | 改成 | 理由 |
|---|---|---|
| 更新当前值 | 记录当前值（不写设备） | 与"下发"区分后果 |
| 下发目标值 | 下发目标值（写入设备并等待回读） | 复用「常用命令」已经说清的措辞 |
| 接管自动 | 接管自动调度 | 补全宾语 |

三者点击后都应有一句确认，说明"是否影响设备"。

### A3 画布页 · 头部说明

| 现在 | 改成 |
|---|---|
| 配置保存在业务节点上，跟随节点权限 | 画面跟随所在站点，按账号权限显示 |
| 画面所属节点 / 整个设备树（下拉） | 显示范围：整个站点 / 指定设备 |
| 下发 | 下发到画面（写入设备前会确认） |

### A4 历史页 · 顶部限制说明

| 现在 | 改成 |
|---|---|
| 每次每点最多 2000 条；完整导出最多 10000 条，超限会明确拒绝。 | 单次查询最多返回最近 2000 条数据；导出超出上限时会拒绝并提示缩小范围。 |
| 缺失段不插值；缺口依据声明采样周期的 3 倍或明确质量事件。 | 数据缺失处不补值；断线区间会明确标出。 |
| 聚合（下拉） | 统计方式：原始数据 / 5 分钟平均 / 1 小时平均 |
| 对比点位 | 选择点位 |

### A5 运行输入与计算（客户可见抽屉）

| 现在 | 改成 |
|---|---|
| 虚拟输入 | 模拟输入（不影响设备） |
| 只读计算点 / 计算点 | 计算值（自动更新，不写设备） |
| 独立非物理输入：不写设备，不代表实测。配置保存为草稿，明确应用后才生效。 | 模拟输入只参与计算，不会写设备，也不代表实测。 |

### A6 常用命令（客户可见抽屉）

| 现在 | 改成 |
|---|---|
| 先在"通道 → 端口配置"绑定 Profile，Profile 里的命令会出现在这里。 | 当前没有可用的命令；如需添加，请联系交付人员。 |

### A7 顶部工具栏

| 现在 | 改成 |
|---|---|
| 运行输入与计算 | 模拟输入与计算 |
| 常用命令 | 常用操作 |
| 班次交接 | 交接班记录 |
| 项目 1 / 1 | 站点 1 / 1 |

## B. 结构问题（不是文案能解决）

### B1 站点根被当成设备显示

设备树里出现一台名为 **FastIOT** 的"设备"，实际是站点根节点（`type=device` 的根）。客户会以为现场真的有一台叫 FastIOT 的设备。

- 改法：设备树把站点渲染为容器，不列为设备；根节点不参与设备计数与状态统计。

### B2 班次交接只存在本机浏览器

抽屉原文：「记录只保存在本机浏览器」。

- 后果：换值班人或换设备就看不到上一班记录，"交接"名不副实。
- 改法：记录存到站点（受权限与审计约束），或明确改名为「本机备忘」并移出主导航。

### B3 空指标占满首屏

八个能源指标在完全未接入时仍占满首屏，把真正有用的信息（设备树、最近变化）推到下面。

- 改法：按 A1 隐藏未绑定指标后，再确认首屏顺序。

## C. 不做的事

- 不重做信息架构（分组与页面名保留）
- 不改交付工作台用词
- 不为客户视图新增配置入口

## D. 验收方式

- 用 operator 账号在隔离实例中逐页截图对照
- 每处改动的断言：客户视图中不出现以下词——虚拟输入、计算点、Profile、业务节点、采样周期、聚合、决策表、通道/端口配置
- 结构问题 B1、B2 各自需要一条真实 HTTP 或页面断言，不能只改文案
