# 六张方向卡（FastIOT 总览 · 客户大屏）

共同输入见 `product-facts.md`；三版同内容、1440×900、单文件 HTML。

## 卡 1｜最佳设计师 A · Massimo Vignelli（标牌系统）

- **逻辑与来源**：Vignelli 的纽约地铁标牌与 Unimark 网格——不是某一件作品的外观，而是“用编号、规则线和字号层级把复杂系统讲清楚”的方法。无截图：这是方法而非单一作品。
- **借的是什么**：左侧一条编号索引（01 现场 / 02 区域 / 03 设备），正文用严格两栏网格与 1px 规则线分隔；标题与正文靠字号与字重拉开，不靠色块。量出来的规则：索引列宽约 180px、正文 14px、标题 28–40px、规则线 1px、只留一个信号红给告警。
- **不借的、自己长的**：不借 Helvetica 的瑞士白底海报感；底色取自来水管网图纸的冷白，红只给“待处理”，蓝只给“运行”，其余全是墨色。
- **主角素材**：工艺链本身——水箱、泵、管网三个节点用尺寸与位置表达 hydraulic head，不用图标堆。
- **骨架**：左编号索引｜中工艺链横贯｜下设备清单与最近数据两栏｜右窄栏告警与今日执行。
- **胆量花在哪**：整屏只有两种颜色在工作（墨与红），大量留白与规则线承担秩序。
- **form 来自内容的哪里**：台账树的层级被压成编号索引——现场看的是“第几层”，不是花哨的树控件。

## 卡 2｜最佳设计师 B · Dieter Rams / Braun（仪表台）

- **逻辑与来源**：Braun 的仪器逻辑——功能分区、物理旋钮、单一信号色、可读的刻度；不是复刻某一台设备。无截图。
- **借的是什么**：把“操作”做成有物理感的开关与刻度盘，数值紧贴刻度；告警用一盏灯而不是一块彩色卡片。量出来的规则：旋钮直径 56px、刻度环 1px、面板分区由凹槽线分隔、绿只用于“已确认”，琥珀只用于“待处理”。
- **不借的、自己长的**：不借 Braun 的米白与金属银；底色取自夜班控制室的石墨黑，刻度用暖白，绿色压到最低饱和度。
- **主角素材**：1号泵的出口压力表——一根指针、一圈刻度、一个目标值标记。
- **骨架**：左侧设备切换（窄）｜中央仪表台（压力表 + 工艺示意）｜右侧竖向告警灯与今日执行｜底部一条状态刻度带。
- **胆量花在哪**：把“当前值 0.42 MPa”做成一块真实的表盘，其余数据退到刻度与标签。
- **form 来自内容的哪里**：泵房值班人先看压力表，再看别的；仪表台就是这个现场的实物形状。

## 卡 3｜现实参照 A · Home Assistant 演示（refs/homeassistant.png）

- **逻辑与来源**：官方在线演示，已亲眼看过：左侧 64px 图标栏，内容按“房间”分组，每组 2–3 列紧凑实体卡；白卡在 #f4f4f4 上，圆角约 8px，正文 14px、标签 12px；颜色只标状态（橙=开、灰=关）。
- **借的是什么**：**按区域分组、组内只放状态与一个主值**的扫读节奏；量出来的规则：分组标题 14px 加图标、卡间距 8px、每组 3 列、状态字在右上。
- **不借的、自己长的**：不借它的白卡＋彩色图标＋橙色开关；我们的分组是台账层级，主值是工程单位，颜色只给告警与运行。
- **主角素材**：设备分组本身。
- **骨架**：顶栏状态条｜左侧台账｜中间“区域分组”设备卡｜右侧告警。
- **胆量花在哪**：把“设备清单”做成可扫读的分组卡，而不是表格。
- **form 来自内容的哪里**：现场值班是“先看哪一区”，不是“先看哪一行”。

## 卡 4｜现实参照 B · ThingsCloud 可视化看板（refs/thingscloud-board.png）

- **逻辑与来源**：官方文档里的看板示例，已亲眼看过：左侧对象树约 220px，右侧彩色组件网格（地图、仪表、柱状、刻度），是零代码搭建器的典型面貌。
- **借的是什么**：**对象树在左、数据在右**的空间关系，以及“树即导航”的机制；不借它的组件色彩与搭建器气质。
- **不借的、自己长的**：紫/青/黄的多色组件、圆角卡片墙、地图底图；我们的颜色只表达状态，版面由规则线组织。
- **主角素材**：对象树与当前层的工艺链。
- **骨架**：树｜当前层大屏。
- **胆量花在哪**：树本身做成可读的“层索引”，而不是文件管理器。
- **form 来自内容的哪里**：交付人员按台账交付，客户也按台账找现场。

## 卡 5｜秒数轮盘 · 网页 7 号「复古未来太空图录 Cosmic Retro-Futurism」（web/07 样张，已看）

- **逻辑与来源**：秒数 46，46 % 20 + 1 = 7；样张为奶纸底＋钴蓝＋黑的三分栏，细线轨道图，衬线大标题与蓝色斜体副题。
- **借的是什么**：**用一条细线轨道图承载主对象**，节点是圆点、标签贴着轨道；量出来的规则：奶底 #F0EAD8 约占 2/3、黑栏约占 1/3，钴蓝 #2B4F91 只给主对象，轨道线 1px，标题衬线 40–64px、正文 15px。
- **不借的、自己长的**：不借“天文台/行星”的题材隐喻与英文斜体；轨道改成能流/水流回路，标签用中文工程单位，黑栏放告警与今日执行。
- **主角素材**：一条闭合的能流回路（光伏→PCC→储能→负载），圆点是设备，线是功率方向。
- **骨架**：左侧奶纸 2/3 放回路与指标｜右侧黑栏放告警、今日执行、最近数据。
- **胆量花在哪**：把 SCADA 的工艺图画成一张技术图录，而不是动画大屏。
- **form 来自内容的哪里**：能量本来就是回路；水也是回路。现场的对象关系天然是“线＋点”。

## 卡 6｜秒数轮盘 · 东亚 11 号「佐藤可士和 极简符号」（east/11，样张未打开）

- **逻辑与来源**：秒数 46，46 % 12 + 1 = 11，佐藤可士和的极简符号方法——每屏一个符号、一句结论、极少颜色。
- **借的是什么**：一层一个符号（现场=方框、区域=双线、设备=圆点）＋一句结论＋一个大数字。
- **不借的、自己长的**：不借高饱和单色块的海报感；用纸白与一条深色底线。
- **主角素材**：符号系统。
- **骨架**：单列居中，符号在上、结论在中、数字在下。
- **胆量花在哪**：去掉几乎所有界面框架。
- **form 来自内容的哪里**：台账层级本身就是符号系统。
- **备注**：未亲眼打开该风格样张，若选中会先补看再开工。

## 选哪三张

选 **卡 1（Vignelli 标牌）＋卡 2（Rams 仪表台）＋卡 5（Cosmic 图录）**：

1. 三种骨架不同：编号索引／仪表台／回路图录；三种温度：冷白秩序／石墨夜班／奶纸技术。
2. 都不撞当前原型（浅蓝玻璃卡片墙）；卡 4 的看板气质正是我们要避开的。
3. 卡 5 是唯一“用力”的一版，但去掉它信息会更糊（回路是内容本身），保留。
4. 卡 3 的机制（区域分组）已被卡 1 的设备清单吸收；卡 6 过于单薄，留作备选。
