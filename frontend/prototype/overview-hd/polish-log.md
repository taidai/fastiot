## dir-1 · 标牌系统（Vignelli）

第一轮看到的最伤三处：
1. 工艺链节点被 `.run` 类误伤（与“今日执行”行的 flex 规则同名），值和小字挤成一行、压住横线。→ 改类名 `.live`，链路线改为纯 CSS 箭头。
2. 下半屏约 300px 空白。→ 最近数据加到 8 行；底部加“今日电量/运行时长/通信成功率/新鲜度 + 24 小时柱图”带，并以页脚线收口。
3. 右栏底部空。→ 加“交接”块（上一班留言），把右栏撑满。

## dir-2 · 仪表台（Braun）

第一轮看到的最伤三处：

## dir-3 · 技术图录（Cosmic）

第一轮看到的最伤三处：
1. 泵的标签与数值压在椭圆轨道上。→ 名称上移、数值下移、小字再下移，viewBox 加高到 346。

4. 运行值没有颜色。→ 泵的“运行”用钴蓝，与样张的单一强调色一致。

## 第三轮 · 玻璃磨砂（用户否掉纸面后）

第一轮看到的最伤三处：
1. 玻璃切换浮在底部压住内容 → 收进顶栏「外观」弹出面板，默认日间。
2. 磨砂几乎看不出来（背景是平涂渐变）→ 背景加管线图（圆、管、矩形），加大色斑，面板才透出可辨认的底。
3. 日间太洗白、面板边界弱 → 加深底色与色斑，面板透明度降到 42%，边框加亮，阴影加重；夜间/青玻璃同步校正。
4. 左下设备面板留白 → 设备清单下补“最近变化”三条。
5. 「外观」弹层被侧栏盖住（backdrop-filter 形成层叠上下文）→ 顶栏升 z-index，弹层改为不透明玻璃底。

透明度：滑杆 20–85%，默认 42%，`--glass` / `--glass-strong` 实时改写；设置存 localStorage，刷新后保持（实测 70% 刷新仍为 70%）。手机端隐藏「外观」入口，沿用默认日间 42%。

## 验收导向补齐（五项）

1. 通用状态机：转移可编辑，事件可模拟；许可/无故障/SOC/电流守卫不满足时保持原状态并说明原因。
2. 交付闭环：预检失败阻断发布；导入→现场重绑→运行分步完成；依赖不匹配拒绝导入；新实例恢复采集且不重放旧命令。
3. 异常路径：操作超时显示结果未知、拒绝不下发、离线不显示旧值；告警恢复入历史，再次触发沿用同一卡并累计次数。
4. 聚合与历史质量：聚合定义可配算子/窗口/质量策略，聚合点显示值、成员和窗口滞后；历史表有失效与断线，曲线对缺失段断开。
5. 权限与证据：角色×动作×对象矩阵和李工拒绝示例；验收证据 JSON 可下载，含预检、映射差异、包内容、导入状态与审计。

全量回归：六步、四段式规则、批量接入、配界面、绑定、总览、Profile 接入、状态机、交付、异常路径全部通过；控制台无错误。
